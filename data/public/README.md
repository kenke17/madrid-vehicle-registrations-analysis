# Public aggregated results

This directory contains small aggregated outputs derived from the analytical
workflow.

The files do not contain individual vehicle-registration records. They are
included to make the main findings of the project inspectable without
redistributing the original or processed DGT microdata.

Planned outputs include:

- Annual registration totals.
- Monthly registration totals.
- Propulsion-technology evolution.
- Municipal registration rankings.
- FAMD eigenvalues.
- Final cluster profiles.

The original fixed-width files, the processed master dataset and intermediate
RDS objects are excluded from version control.
